# ארכיטקטורה — PRINTYZ Clicker Studio

## זרימת נתונים (מקור אמת אחד)

```
Project (model/project.py)          ← הממשק עורך רק את זה
   │  sync_keys_from_text()          (text/engine.py)   שם → מקשים, מזהים יציבים, RTL/LTR
   ▼
compute_layout()  (layout/engine.py) ← המקום היחיד שמחשב מיקומים
   ▼
build_project()   (geometry/builder.py)
   ├─ build_body()      geometry/body.py      גוף, תאים, פלטת MX, שקעים, מחזיק מפתחות
   ├─ keycap_body()     geometry/keycap.py    כובע לפי סגנון + תושבת צלב
   ├─ build_legend()    geometry/lettering.py גליף אמיתי, התאמה לשטח, עיבוי
   └─ switch_proxy()    geometry/switch_proxy.py (לתצוגה בלבד)
   ▼
BuildResult  ──►  validate()        validation/checks.py
             ──►  render_set()      render/preview.py   (z-buffer, ללא עיוותים)
             ──►  Viewer3D          ui/viewer.py        (VTK, אותן רשתות בדיוק)
UI: ui/main_window.py ← ui/controller.py (בנייה ברקע, debounce) ← ui/pages.py
             ──►  export_all()      export/             STL / STEP / 3MF / JSON / דוח
```

## מערכת צירים ומידות
- מ״מ בלבד. מרכז הגוף ב־(0,0); z=0 תחתית הגוף.
- `pitch = upper_recess + partition = 20.75 + 2.0 = 22.75`.
- גוף יחיד: 23.80 × 23.80 × 17.64 (נמדד).
- פלטה: z = 10.5–12.0, חור 13.90 (נבחר בבדיקה), כיס תחתון 17.10 עם מעבר 45° ל־15.90 (מונע גשר רחב).
- כובע במנוחה: תחתית החצאית ב־z=18.0; בלחיצה מלאה (4 מ״מ) — 2.0 מ״מ מעל הפלטה.
- ערכים המסומנים `VERIFY` ב־`config/mechanical.py` הם הערכות הנדסיות שיש לאמת מול קובץ המקור.

## אסטרטגיית הדפסה
- Flush / Engraved: הכובע מודפס **הפוך** (פני הכובע על המגש) → האותיות הן 3 השכבות הראשונות, צבע חד.
- Raised: הכובע מודפס זקוף.
- 3MF: אובייקט לכל חלק מודפס; כובע עם אות = אובייקט אחד עם 2 Parts, לכל Part מספר אקסטרודר (AMS slot).
