# אתר Printyz — מדריך

## מה יש באתר (שלב 1)
- **דף בית** עם עדכונים ומוצרים נבחרים, **גלריה** של מוצרים (תמונות, תיאור, מחיר).
- **מחולל קליקר** למחשב ולנייד: טקסט → גופן → עיצוב → גוף → צבעים → סמלים → הזמנה.
  כל שינוי בונה את **הקליקר האמיתי** בשרת (אותו מנוע כמו התוכנה במחשב) ומציג אותו בתלת־ממד (~1.5 שניות).
- **מחיר אוטומטי** (ברירת מחדל ₪6 למקש; כל התוספות ניתנות לעריכה בניהול).
- **הזמנה**: שם, אימייל, טלפון, הערות, סימון הסכמה לדיוור (לא מסומן מראש), אישור תקנון.
  - אתה מקבל **אימייל** עם קובץ ההזמנה (`.printyz-order`) מצורף + קישור לניהול.
  - אופציונלי: **הודעת וואטסאפ חינמית לעצמך** (CallMeBot).
  - הלקוח מקבל אימייל עם **קישור מעקב** אישי.
- **ניהול** (`/admin`, בסיסמה):
  - הזמנות לפי סטטוס: ממתינה לאישור → אושרה (מחיר סופי + קישור תשלום Bit/PayBox) → שולמה →
    בייצור (מספר ימים) → מוכנה → נמסרה. בכל שלב הלקוח מקבל אימייל, ויש כפתור
    **"שליחת העדכון ללקוח בוואטסאפ"** שפותח את הוואטסאפ שלך עם הודעה מוכנה (חינם).
  - הגדרות: צבעי מלאי, ברירות מחדל, אילו אפשרויות מוצגות ללקוח, מחירים, פרטי קשר — **מתעדכן באתר מיד**.
  - גלריה, עדכונים, רשימת דיוור (הורדה ל־Excel).
- דפי **תקנון / פרטיות / נגישות** — טיוטות שצריך לעבור עליהן לפני עלייה לאוויר.

## הרצה מקומית במחשב (לבדיקה)
```
.venv\Scripts\pip install -e ".[web]"
set PRINTYZ_ADMIN_PASSWORD=סיסמה-לבדיקה
set PRINTYZ_EMAIL_BACKEND=console
.venv\Scripts\uvicorn printyz_web.app:app --port 8000
```
ואז לפתוח בדפדפן: http://localhost:8000 (ניהול: http://localhost:8000/admin)

## עלייה לאוויר (כשתאשר)
1. **דומיין** — למשל `printyz.co.il` (כ־₪60–100 לשנה) ברשם מוסמך של איגוד האינטרנט.
2. **שרת** — שרת וירטואלי קטן (למשל Hetzner CX22, כ־₪20 לחודש). המחולל בונה גאומטריה אמיתית,
   ולכן אחסון "סטטי" חינמי לא מספיק.
3. בשרת: להתקין Docker, להעתיק את הפרויקט, ואז:
   ```
   cd deploy
   cp .env.example .env      # למלא בשרת בלבד — לא לשלוח בצ'אט
   docker compose up -d --build
   ```
   Caddy מנפיק תעודת HTTPS חינמית אוטומטית.
4. להפנות את רשומת ה־DNS של הדומיין (A) לכתובת ה־IP של השרת.

## אימייל
מומלץ להשתמש בתיבת העסק. ב־Gmail: להפעיל אימות דו־שלבי וליצור **App password**, ואז
`PRINTYZ_SMTP_HOST=smtp.gmail.com`, `PRINTYZ_SMTP_PORT=587`, המשתמש = כתובת המייל, הסיסמה = App password.

## וואטסאפ חינמי
- **אליך (התראה על הזמנה חדשה):** CallMeBot — שולחים פעם אחת מהטלפון שלך את הודעת ההפעלה לפי
  ההוראות באתר שלהם, מקבלים מפתח, ושמים אותו ב־`.env` (`PRINTYZ_CALLMEBOT_APIKEY`, `PRINTYZ_OWNER_WHATSAPP`).
- **ללקוח:** בלי API בתשלום — בדף ההזמנה בניהול יש כפתור שפותח וואטסאפ עם ההודעה מוכנה; לוחצים "שלח".

## תשלום
שלב 1: אחרי אישור ההזמנה מדביקים קישור תשלום (Bit / PayBox / העברה) — הלקוח רואה כפתור "מעבר לתשלום"
בדף המעקב ובאימייל, ואתה מסמן "התשלום התקבל".
שלב 2 (בהמשך): חיבור לספק סליקה (כרטיס אשראי + Bit) עם אישור תשלום אוטומטי.

## עוסק פטור
המחירים באתר הם סופיים (ללא מע"מ). יש להוציא קבלה על כל תשלום (למשל באפליקציית קבלות).
